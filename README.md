Very simple c++ calculator that contains 4 arithmetic operations, and a confirmation check if what you inputted is what you want!

Compile it the same way you would compile a standard c file on your os (Ill make a cmake file soon!):

Download the file, cd into the folder containing it and run one of these commands depending on your OS

Windows: g++ calculator.cpp -o calculatorv1.exe

Linux: g++ calculator.cpp -o calculatorv1

macOS: clang++ calculator.cpp -o calculatorv1

On windows, run using .\calculatorv1.exe, and on linux and macOS, run using ./calculatorv1!
